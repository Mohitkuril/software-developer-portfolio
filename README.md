## 💻 About This IDE Portfolio Application

This portfolio is built as an **interactive, VS Code-themed Web Application** featuring a file explorer, tab navigation, status bar, command palette, interactive terminal, dynamic experience counter, and a Copilot AI assistant that indexes the candidate's PDF resume in real time!

### 🏗️ Architecture & Core Files

```
software-developer-portfolio/
├── public/
│   └── Mohit_Kuril_Full_Stack_Software_Engineer_Resume.pdf  # Resume PDF
├── src/
│   ├── components/
│   │   ├── EditorViews.tsx        # Renderers for home, about, projects, skills, experience, contact, readme
│   │   ├── CopilotPanel.tsx       # AI assistant reading PDF resume via PDF.js + Groq API
│   │   ├── Explorer.tsx           # VS Code style file navigation
│   │   ├── MenuBar.tsx & StatusBar.tsx
│   │   └── PortfolioTerminal.tsx  # Interactive terminal shell
│   ├── siteConfig.ts              # Data source & dynamic experience calculation
│   ├── resumeDownload.ts          # Same-origin PDF download helper
│   ├── files.ts                   # Explorer file entries definition
│   ├── App.tsx & main.tsx
│   └── portfolio.css & ref-ui.css
├── package.json
└── README.md
```

### ⚡ Development & Local Setup

```bash
# Clone repository
git clone https://github.com/Mohitkuril/software-developer-portfolio.git

# Navigate into directory
cd software-developer-portfolio

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
